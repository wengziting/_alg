
## 方法與時間複雜度比較

1. **方法 1 (`2**n`)**：直接用 Python 內建運算
   * 速度：**最快** $O(1)$
2. **方法 2a (`power2n(n-1) + power2n(n-1)`)**：沒優化的雙重遞迴
   * 速度：**極慢** $O(2^n)$
3. **方法 2b (`2 * power2n(n-1)`)**：單一遞迴
   * 速度：**快** $O(n)$
4. **方法 3 (`遞迴 + 查表`)**：把算過的答案記下來（Memoization）
   * 速度：**快** $O(n)$

---

## 測試結果 ($n = 100$)

| 方法 | 執行時間 | 結果說明 |
| :--- | :--- | :--- |
| **方法 1** | `< 0.01 ms` | ⚡ 瞬間算完 |
| **方法 2a** | 算不出來*| ❌ 電腦會卡死 |
| **方法 2b** | `~ 0.05 ms` | 🟢 順利完成 |
| **方法 3 ** | `~ 0.08 ms` | 🟢 順利完成 |

---

## 關鍵分析

### 1. 為什麼方法 2a算不出來？
* 計算 $2^{100}$ 時，它會拆成 2 個 $2^{99}$，再拆成 4 個 $2^{98}$……
* 總共會呼叫函式 **超過 $10^{30}$ 次**。

### 2. 為什麼方法 3 可以算出來？
* 程式碼同樣寫了 `power2n(n-1) + power2n(n-1)`，但加號右邊的答案在左邊算完時就已經儲存好了

---

## 結論
* **不要寫出會重複計算的遞迴**（像方法 2a）。
* 遇到重複計算問題時，**用字典查表** 可以讓速度可以更快
