
# 梯度下降法 
## 1. 數學背景與目標
在此實作中，我們的目標是尋找以下一元二次函數的最小值：
目標函數：f(x) = x^2 - 4x + 4
導數函數 (梯度)：f'(x) = 2x - 4
根據微積分基本定理，當導數 f'(x) = 0 時，函數有極值。解方程式 2x - 4 = 0 可知，理論上的最小值發生在 x = 2。我們將利用梯度下降法透過程式自動迭代逼近這個數值。
## 2. 核心元件設計
要將梯度下降法套用至 generic_iterator，我們需要定義三個核心要素：狀態推進函數、收斂判定條件以及初始狀態。
### 2.1. 狀態推進函數 (Transition Function)
df = lambda x: 2.0 * x - 4.0
learning_rate = 0.1
transition = lambda x: x - learning_rate * df(x)


學習率 ：設定為 0.1。這決定了每次朝梯度反方向移動的步伐大小。
更新邏輯：新的狀態 (猜測值) 等於舊的狀態減去學習率乘上該點的梯度。在數學上表示為：x_new = x_old - \eta * f'(x_old)。
### 2.2. 收斂判定函數 
converged = lambda old, new, i: abs(new - old) < 1e-6


判定邏輯：計算本次迭代產生的新值與上一次的舊值之間的絕對差。
終止條件：當差值小於 1e-6 (即 0.000001) 時，我們認為數值已經穩定，不會再有大幅變動，此時觸發收斂終止迴圈。
### 2.3. 初始狀態 (Initial State)
我們將起點設定為 x_0 = 0.0。演算法將從這個點開始，根據梯度指示的方向逐步下山。
## 3. 執行與輸出結果
result, iters = generic_iterator(transition, converged, initial_state=0.0)
print(f"結果: 最小值發生在 x = {result:.6f} (耗時 {iters} 次迭代)\n")


程式將上述定義的 transition 與 converged 傳入通用框架中執行。最終輸出會顯示經過了幾次迭代後，收斂至接近 2.000000 的結果，完美印證了理論值。
