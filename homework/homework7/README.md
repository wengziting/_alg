# 1. 非動態規劃：純遞迴（Pure Recursion）

## 邏輯說明

這個版本的核心思想是「暴力窮舉所有可能性」。我們從字串的最後一個字元開始比對。

### 終止條件（Base Case）

- `if i == 0: return j`：如果 `word1` 已經空了（比對完了），而 `word2` 還剩下 `j` 個字元，代表必須對 `word1` 進行 `j` 次插入操作。
- `if j == 0: return i`：如果 `word2` 已經空了，而 `word1` 還剩下 `i` 個字元，代表必須進行 `i` 次刪除操作。

### 字元相同時

```python
if word1[i - 1] == word2[j - 1]:
    return helper(i - 1, j - 1)
```

如果最後一個字元剛好一樣，就不需要花任何代價去修改它，直接遞迴比對前面剩下的字元。

### 字元不同時

程式會分支出三個方向（插入、刪除、取代），並在其中挑選一個代價最小的結果，再加上 1。

- `helper(i, j - 1)`：代表在 `word1` 後面插入一個與 `word2[j-1]` 相同的字元，因此 `word2` 的指標往前移（`j-1`）。
- `helper(i - 1, j)`：代表把 `word1` 當前的字元刪除，因此 `word1` 的指標往前移（`i-1`）。
- `helper(i - 1, j - 1)`：代表把 `word1` 當前字元取代成 `word2` 的字元，兩者指標同時往前移。

### 缺點

因為沒有記憶功能，同一個子問題（例如 `helper(2, 2)`）會被不同的遞迴路徑重複計算，導致時間複雜度呈指數級成長，效率非常差。

# 2. 動態規劃：由底向上表格法（Bottom-Up Tabulation）

## 邏輯說明

動態規劃解決了純遞迴「重複計算」的問題，改用「填表格」的方式，由淺入深地計算答案。

### 建立表格（dp 陣列）

宣告一個大小為 `(m + 1) × (n + 1)` 的二維陣列。

`dp[i][j]` 的白話文意思是：「把 `word1` 的前 `i` 個字元變成 `word2` 的前 `j` 個字元，最少需要幾步？」

### 初始化邊界

先將第一列與第一行填好：

- `dp[i][0] = i`：將 `word1` 的前 `i` 個字元全部刪除，才能變成空字串。
- `dp[0][j] = j`：將空字串轉換成 `word2` 的前 `j` 個字元，需要進行 `j` 次插入操作。

這對應到「空字串對上任何字串」的基礎編輯次數。

### 雙層迴圈填表

我們從左到右、由上到下逐格填滿表格。

**如果當前字元相同：**

```python
dp[i][j] = dp[i - 1][j - 1]
```

直接使用左上角的值，代表不需要增加編輯成本。

**如果當前字元不同：**

```python
dp[i][j] = 1 + min(
    dp[i - 1][j],      # 刪除
    dp[i][j - 1],      # 插入
    dp[i - 1][j - 1]   # 取代
)
```

這裡的三個值分別對應：

- 上方的格子：刪除。
- 左方的格子：插入。
- 左上方的格子：取代。

只要查看這三個已經計算好的鄰居，取最小值再加上這一步的 `1` 即可。

# 3. 空間優化版：滾動陣列（Space Optimization）

## 邏輯說明

### 核心概念

觀察動態規劃的填表過程可以發現：當我們在計算第 `i` 行時，其實只需要用到上一行（第 `i - 1` 行）的資料，以及當前行已經計算好的部分資料。更上面的行數（第 `i - 2` 行以上）都不需要保留。

### 實作技巧

因此，我們不需要浪費記憶體去開一個完整的 `(m + 1) × (n + 1)` 二維矩陣，只需要維持一個一維陣列 `dp` 記錄上一行的狀態，再用一個新的陣列 `new_dp` 計算當前行。

當這一行計算完成後，再將 `new_dp` 指定給 `dp`，循環使用陣列來計算下一行。

透過這種方式，可以將空間複雜度從 `O(m × n)` 降低到 `O(n)`。

### 三種方法的比較

| 方法 | 核心概念 | 時間複雜度 | 空間複雜度 |
|---|---|---|---|
| 純遞迴 | 窮舉所有可能性 | 指數級 | 遞迴堆疊，最壞情況可達 O(m+n) |
| 動態規劃 | 使用二維表格儲存結果 | O(m × n) | O(m × n) |
| 滾動陣列 | 只保留計算所需的行 | O(m × n) | O(n) |

其中，`m` 代表 `word1` 的長度，`n` 代表 `word2` 的長度。
