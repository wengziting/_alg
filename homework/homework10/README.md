## 0. 測試題目與真值

`f(x) = x₁² + x₂² + ... + xₙ²`,區域 `[0,1]ⁿ`。

- 每一維 `∫₀¹ x² dx = 1/3`,其餘維度的積分各為 1,所以每一項貢獻 1/3。
- n 項相加,真值 = **n/3**。n = 1, 2, 5, 100 的真值分別是 0.3333、0.6667、1.6667、33.3333。
- 梯度 `∇f = (2x₁, ..., 2xₙ)`,在 (1,2,3) 的真值是 (2, 4, 6)。

## 1. 單變數數值微分與積分

### 微分:中央差分

```
f'(x) ≈ (f(x+h) − f(x−h)) / (2h)
```

- 把 f(x±h) 用泰勒展開,一階以外的奇數項相減後抵消,截斷誤差只剩 `h²·f'''(x)/6`,屬於二階精度。
- 若用前向差分 `(f(x+h) − f(x))/h`,誤差是 `h·f''/2`,只有一階。
- h 不是越小越好:h 太小時,f(x+h) 與 f(x−h) 幾乎相等,相減會損失有效位數,捨入誤差約 `ε/h`(ε ≈ 1e-16)。兩種誤差加起來,最佳 h 約為 `ε^(1/3) ≈ 6e-6`,所以預設 `h = 1e-5`。
- 實測:d/dx x² 在 x=1,結果 2.000000000002,誤差約 2e-12。

### 積分:中點黎曼和

把 [a, b] 切成 n 格,每格寬 `dx = (b−a)/n`,取每格中點的函數值乘 dx 後加總。

- 程式中 `x = a + (arange(n) + 0.5) * dx` 就是所有格子的中點。
- 誤差約 `(b−a)·dx²·f''/24`,二階精度。左、右端點法只有一階,中點法在相同格數下準很多。
- 實測:∫₀¹ x² dx(n = 10⁵ 格)= 0.33333333332500,誤差約 8e-12。

## 2. 單變數蒙地卡羅積分

```
∫ₐᵇ f(x) dx ≈ (b−a) · mean( f(X₁), ..., f(X_N) ),  Xᵢ ~ Uniform(a, b)
```

- 原理:積分 = 區間長度 × f 的期望值,用隨機樣本的平均值來估計期望值。
- 標準誤差 `(b−a)·σ_f / √N`。x² 在 [0,1] 上的變異數是 1/5 − 1/9 = 4/45,σ ≈ 0.298,N = 10⁶ 時預期誤差約 3e-4。
- 實測:0.333561,誤差 2.3e-4,與預期相符。
- 一維時黎曼法比蒙地卡羅準非常多(8e-12 對 2e-4),蒙地卡羅的價值在高維度。

## 3. n 變數微分(梯度)

```
∇f(x) = ( ∂f/∂x₁, ..., ∂f/∂xₙ )
```

- 每個分量各做一次中央差分,只擾動第 i 個座標:建立只有第 i 個位置為 h 的向量 `e`,算 `(f(x+e) − f(x−e)) / 2h`。
- 共需 2n 次函數呼叫,成本與維度成線性關係,沒有維度災難。
- 實測:f=Σxᵢ² 在 (1,2,3),結果 [2, 4, 6],與解析解 `2x` 相符。

n 變數積分(超體積)見下面第 5 題。

## 4. n 變數蒙地卡羅積分

```
∫ f ≈ V · mean( f(Xᵢ) ),  Xᵢ ~ Uniform([low, high]),  V = Π(highᵢ − lowᵢ)
```

- 在 n 維方盒內均勻抽 N 個點,平均函數值乘上方盒體積 V。
- 本題 low=0、high=1,所以 V = 1。
- 成本是 N × n,對維度線性。

## 5. 黎曼積分 `integral(f, low, high)`

n 由 `len(low)` 決定。做法:

1. 每一維切成 k 格(預設 k = 10),共 kⁿ 個小方盒。
2. 每個小方盒取中心點,體積 `dV = Π (highᵢ − lowᵢ) / kⁿ`。
3. `∫ f ≈ dV · Σ f(中心點)`。

實作重點:

- **編號轉座標**:把 0 到 kⁿ−1 的一維編號當成 k 進位數字,用 `r % k` 取出該維的索引,再 `r //= k` 進位到下一維。這樣不需要 n 層迴圈,也不用 `meshgrid` 一次佔滿記憶體。
- **分批計算**:每次處理 `batch = 200,000` 個點,記憶體用量固定。
- **保護機制**:kⁿ 超過 `max_points`(5×10⁷)就直接丟出 `MemoryError`。

誤差:中點法對每一維的偏差約 `1/(12k²)`,f=Σxᵢ² 共 n 維,總誤差約 `n/(12k²)`。k=10 時,n=1, 2, 5 分別約 8.3e-4、1.7e-3、4.2e-3。中點法對凸函數(x² 是凸的)會略為低估,所以結果都比真值小。

| n | 格點數 kⁿ | 黎曼結果 | 真值 | 誤差 |
|---|---|---|---|---|
| 1 | 10 | 0.332500 | 0.333333 | 8.3e-4 |
| 2 | 100 | 0.665000 | 0.666667 | 1.7e-3 |
| 5 | 10⁵ | 1.662500 | 1.666667 | 4.2e-3 |
| 100 | 10¹⁰⁰ | 無法計算 | 33.3333 | — |

n=100 時即使每維只切 2 格也要 2¹⁰⁰ ≈ 1.3×10³⁰ 個點,而宇宙中的原子數也只有約 10⁸⁰ 個。這就是維度災難,程式會直接報錯。

## 6. 蒙地卡羅法(同題目)

| n | 蒙地卡羅結果(N = 10⁶) | 真值 | 誤差 |
|---|---|---|---|
| 1 | 0.333561 | 0.333333 | 2.3e-4 |
| 2 | 0.666971 | 0.666667 | 3.0e-4 |
| 5 | 1.666219 | 1.666667 | 4.5e-4 |
| 100 | 33.331593 | 33.333333 | 1.7e-3 |

預期誤差可以直接算:各維獨立,所以 `Var(f) = n · 4/45`。n=100 時 σ ≈ 2.98,標準誤差 = σ/√N ≈ 3×10⁻³,實測 1.7×10⁻³,落在一個標準誤差之內。

## 7. 兩種方法比較

| | 黎曼積分 | 蒙地卡羅 |
|---|---|---|
| 成本 | kⁿ,隨維度指數成長 | N × n,隨維度線性成長 |
| 誤差 | 每維 O(k⁻²),但 k 在高維無法加大 | O(N⁻½),與維度無關 |
| 低維(1 到 3 維) | 準確很多 | 較不準 |
| 高維 | 做不到 | 可行 |
| 精度提升 | 加大 k(成本 ×(新k/舊k)ⁿ) | 加大 N(誤差降 10 倍需 100 倍樣本) |

直觀理解:黎曼法要把每個維度都排滿格點,所以維度一多就爆炸;蒙地卡羅是隨機撒點,不管空間多大,撒 N 個點的成本都一樣。

## 8. 使用注意事項

- `integral` / `integral_mc` 的 `f` 必須能一次接受 `(m, n)` 陣列並回傳 `(m,)`,例如 `np.sum(x**2, axis=-1)`。`gradient` 的 `f` 則是接受單一點 `(n,)` 並回傳純量。
- 需要可重現結果時,傳入 `rng=np.random.default_rng(seed)`;不傳則每次呼叫都使用 seed 0。
- 想提升高維精度:增加 N,或改用準蒙地卡羅(`scipy.stats.qmc` 的 Sobol 序列),誤差可接近 O(N⁻¹)。
- 本題 f 是各維可分離的(Σxᵢ²),理論上可以拆成 n 個一維積分再相加,所以 100 維也能精確算,但這是利用函數結構的特例,不是通用的黎曼法。
