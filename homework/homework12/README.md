計算理論詳解:從希爾伯特到喬姆斯基
本文依教材五章(希爾伯特的問題、哥德爾的定理、丘奇的函數、圖靈的機器、喬姆斯基的語法)逐章解說,並補充教材沒講清楚、或說法不夠精確的地方。
第 1 章:希爾伯特的問題
1.1 推論引擎在做什麼
教材的 inference.py 是一個前向推論(forward chaining)系統:
• 事實集合 facts,例如 {A, B}
• 規則庫 rules,例如 E&F=>H
• 每一輪掃描所有規則,如果左式的每個變數都在 facts 裡,就把右式加進 facts
• 直到某一輪沒有新事實產生為止,這叫不動點(fixed point)

這個系統「不夠數學」的原因:它只能推出單一變數(原子命題)。像德摩根定律 ¬(p∧q) ⇔ (¬p∨¬q) 是一條邏輯法則,不是某個變數,這個系統無法表達。
1.2 用公理系統推出真正的定理
教材最後列了三條公理,這是命題邏輯的希爾伯特式公理系統(只用 → 和 ¬):
1.  p → (q → p)
2.  (p → (q → r)) → ((p → q) → (p → r))
3.  (¬p → ¬q) → (q → p)
推論法則只有一條,就是肯定前件(Modus Ponens,MP):有 P,又有 P⇒Q,就得到 Q。從這三條公理加上 MP,就能推出所有命題邏輯的恆真式,包括德摩根定律,這個性質叫做命題邏輯的完備性。
要區分兩種東西:
• 語義上的真(恆真式):在所有真值指派下都為真,可以用真值表驗證。
• 語法上的可證:能從公理經 MP 推導出來。
命題邏輯很特別,兩者剛好相同,而且真值表本身就是判定演算法。真正的難題在於,當系統強到能談整數時,兩者就不再一致。

第 2 章:哥德爾的定理
2.1 羅素悖論為什麼致命
樸素集合論允許「任何性質都能定義一個集合」。令 A = {x | x ∉ x}:
• 若 A ∈ A,依定義 A ∉ A。
• 若 A ∉ A,依定義 A ∈ A。
這等於得到「P ⇔ ¬P」。一旦系統能推出矛盾,按邏輯的爆炸原理,它就能推出任何命題,系統完全失去意義。理髮師悖論是同一件事的白話版。
2.2 ZFC 怎麼避開
關鍵在分類公理(又稱分離公理):
∀A ∃B ∀x (x∈B ⇔ x∈A ∧ P(x))
意思是:不能憑空用性質 P 造出一個集合,只能從已存在的集合 A 裡挑出滿足 P 的元素。所以 {x | x∉x} 根本無法形成,最多只能造出 {x∈A | x∉x}。一個推論是:不存在「所有集合的集合」,否則可以對它做分離,重現悖論。
ZFC 其他公理的功能大致是:
• 外延:兩集合元素相同就相等
• 配對、聯集、冪集:造新集合的方式
• 空集、無窮:保證有起點和無窮集合
• 替代:函數的像是集合
• 正則:禁止集合屬於自己、禁止無窮下降的屬於鏈
• 選擇:可以從一堆非空集合各挑一個元素
2.3 完備定理 vs. 不完備定理
哥德爾完備定理(1929)講的是一階邏輯本身:一個語句在所有模型中都為真,當且僅當它能從一階邏輯的推論規則證明。也就是語義真 ⇔ 語法可證。
第一不完備定理(1931)講的是特定理論:任何一致、公理可被演算法列舉、且足夠強到包含基本算術的理論 T,都存在一個語句 G,T 證不出 G,也證不出 ¬G。
兩者不矛盾,因為「完備」的對象不同:
• 完備定理說「邏輯規則夠用」:凡是在所有模型都真的語句,都有證明。
• 不完備定理說某理論 T 的公理不夠,而且無論再怎麼加公理,只要仍滿足上述條件,都還會有新的不可判定語句。
G 在標準整數模型裡其實是真的,但它不是「所有滿足 T 的模型都真」,所以完備定理不要求它可被證明。
2.4 哥德爾真正的證明思路
教材的 Q 論證只是示意,實際的證明骨架如下:
1.  哥德爾編碼:給每個符號、公式、證明一個整數編號。於是「這串符號是不是一個合法證明」變成整數上的算術性質。
2.  可證性謂詞 Prov(x):用算術語句表達「編號為 x 的公式在 T 中有證明」。
3.  對角線引理:對任意性質 P(x),可以構造一個語句 G,使得 T 能證明 G ⇔ P(⌜G⌝),也就是 G 說的是「我自己具有性質 P」。
4.  取 P(x) = ¬Prov(x),得到 G ⇔ ¬Prov(⌜G⌝),即 G 在說「我不可被證明」。
5.  推論:
    ◦ 若 T 能證 G,則 G 為真,但 G 說自己不可證,矛盾,因此 T 不一致。
    ◦ 所以若 T 一致,T 證不出 G。
    ◦ 而 G 說的正是「我不可證」,所以 G 為真。
要讓 T 也證不出 ¬G,哥德爾原本需要更強的 ω-一致性條件,後來羅薩(Rosser)改良後,只需要一致性就夠了。
教材說「一階邏輯編碼不了 Provable,加入皮亞諾公理後才行」,這個說法稍微偏掉了。重點在於算術夠強,才能把「證明」這個動作變成整數運算。
2.5 第二不完備定理(教材沒提)
一致的、足夠強的理論 T,無法證明自己的一致性。這直接擊中希爾伯特第 2 問題(證明算術公理的相容性):用算術系統自己的方法,證不出自己不矛盾。
2.6 關於皮亞諾公理的小提醒
教材列的六條只含後繼、加法、乘法的基本規則,沒有歸納公理。嚴格說,它比較接近 Robinson 算術的一個子集。但不完備定理對這類「足夠強」的算術系統同樣成立,所以不影響結論。
第 3 章:丘奇的 λ-Calculus
3.1 語法與規則
只有三種項:變數 x、抽象 λx.M(造函數)、應用 M N(呼叫函數)。
• β-歸約:(λx.M) N → M[x:=N],把 M 裡的 x 換成 N。例:(λx. x x) y → y y。
• α-轉換:改約束變數名稱,例如 λx.x 與 λy.y 是同一個函數。
• 多參數靠 Currying:λx.λy.M 就是「吃一個參數,回傳另一個函數」。Python 的 lambda t:lambda f:t 就是這個意思。
3.2 布林
TRUE  = λt.λf. t      # 兩個選項選第一個
FALSE = λt.λf. f      # 選第二個
IF    = λc.λt.λf. c t f
布林值本身就是「選擇器」,IF 只是把條件 c 套用到 t、f 上,不需要 if 語法。其他運算:
• NOT c = c FALSE TRUE
• AND p q = p q p:p 為真就回傳 q,為假就回傳 p(也就是 FALSE)
• OR p q = p p q:p 為真就回傳 p(TRUE),為假就回傳 q
3.3 邱奇數:整數就是「套用 n 次」
0 = λf.λx. x
1 = λf.λx. f x
2 = λf.λx. f (f x)
n = λf.λx. fⁿ(x)
• SUCC n = λf.λx. f (n f x):多套一次
• ADD m n = n SUCC m:把 SUCC 套 n 次到 m 上
• MULT m n = λf. m (n f):先把 f 套 n 次,再把這整個動作套 m 次
• POWER x y = y x:y 次地套用「乘 x」,所以是 x 的 y 次方
• IS_ZERO n = n (λ_. FALSE) TRUE:n 次套用「回傳 FALSE」,只有 n=0 時保持 TRUE
減法/前驅(PRED)最難,因為只能「往前套」,不能「倒退」。程式碼用的是 Kleene 的技巧:把狀態包成 pair (上一個值, 目前值),套 n 次之後取出「上一個值」。這也是教材說它「需要另外解釋」的原因。
3.4 遞迴與 Y combinator
λ 項沒有名字,所以函數無法在自己內部呼叫自己。Y combinator 解決這個問題:對任何函數 f,Y f = f (Y f),也就是 Y f 是 f 的不動點。
教材的 Python 版本是:
Y = lambda f: (lambda x: f(lambda y: x(x)(y))) (lambda x: f(lambda y: x(x)(y)))
這其實是 Z combinator:多包了一層 lambda y: x(x)(y)。原因是 Python 是傳值呼叫(strict),會先求值參數,如果直接寫 f(x(x)),x(x) 會立刻無限展開。包成 lambda 後延遲到真正需要時才展開。
同理,教材的 IF(c)(lambda _: ...)(lambda _: ...)(NIL) 也是在延遲求值:兩個分支要包成函數,否則兩邊都會被先算出來,遞迴就停不下來。
3.5 CONS / CAR / CDR
CONS x y = λf. f x y:資料就是「等著被餵一個選擇函數」的函數。CAR p = p TRUE 取前者,CDR p = p FALSE 取後者。有了配對,就能做出串列、RANGE、MAP,也就是 Lisp 的基礎。
3.6 丘奇的不可判定結果
丘奇 1936 年證明:沒有演算法能判定兩個 λ 項是否 β-等價。教材給的直覺是「不能判定兩個函數是否功能相同」,方向正確,但要注意兩個細節:
• 這個定理針對的是 λ 項之間「能否經歸約互相轉換」。
• 一般程式語言版本是 Rice 定理:任何關於程式「行為」的非平凡性質都不可判定。
教材 fequal(A, B) 的反例很直觀:如果 A() 不停,整個比較就卡住,你無從分辨是「慢」還是「永遠不停」。
這個結果當時直接回答了希爾伯特的判定問題(Entscheidungsproblem),也就是綱領第五點:不存在能判定所有一階邏輯語句的演算法。

4.2 圖靈機
圖靈機就是 FSM 加上可讀可寫、可左右移動的無限磁帶。每一步 δ 根據「目前狀態 + 讀到的符號」決定:下一個狀態、寫入什麼、往哪移。
這個小改動帶來質的飛躍:FSM 只能靠有限狀態記憶,連數 aⁿbⁿ 都做不到;圖靈機可以把磁帶當作無限記憶體。
4.3 aⁿbⁿcⁿ 圖靈機逐步走一遍
演算法是「每輪消掉一個 a、一個 b、一個 c」:
• 狀態 0:讀到 a 就擦成 _,進入狀態 1 往右
• 狀態 1:跳過 a 和已標記的 x,遇到 b 就標成 x,進入狀態 2
• 狀態 2:跳過 x 和 b,遇到 c 就標成 x,進入狀態 5 往左
• 狀態 5:一路往左退,碰到 _(剛才被擦掉的 a 的位置)回到狀態 0 往右,開始下一輪
• 狀態 0 若看到 x,代表 a 都用完了,進入狀態 4 檢查剩下的是不是全是 x,最後遇到空白進入接受態 3
用 aabbc 追蹤:第一輪成功消去一組,第二輪標完 b 之後找 c,卻先撞上空白,而狀態 2 沒有 (2,_) 規則,於是沒有轉移 = 拒絕,輸出 False,正確。
4.4 程式上的小瑕疵
• 輸入後面只補了 8 個空白(tape+'________'),輸入夠長就會超出範圍,嚴格說這不是「無限」磁帶。
• 規則裡寫的是小寫 x,但磁帶字母表宣告的是大寫 X。模擬器不會檢查這點,所以能跑,但嚴格來說不一致。
• 圖靈機可能根本不停(進入迴圈),這個範例剛好沒有這種情況。
4.5 停機問題的證明細節
假設存在總是會停機的判定器 isHalt(code, data),建構:
U(code):
    if isHalt(code, code) == 1: 無窮迴圈
    else: 立刻停止
問 U(U) 的行為:
• isHalt(U,U)=1(說 U(U) 會停)⇒ U 進入迴圈 ⇒ U(U) 不停,判斷錯。
• isHalt(U,U)=0(說 U(U) 不停)⇒ U 立刻停 ⇒ U(U) 會停,判斷錯。
兩種都錯,所以 isHalt 不存在。這就是對角化,和羅素悖論、哥德爾的「我不可證」同一個骨架:自己對自己做反向的判斷。
補充兩點教材沒提的:
1.  停機問題是可辨識但不可判定:你可以模擬程式,停了就回答「會停」,但不停時你永遠沒機會說「不會停」。
2.  一旦有一個不可判定問題,就能用歸約證明其他問題也不可判定。例如「這個程式會不會輸出 5」、「兩個程式是否等價」。
4.6 一個需要修正的說法
教材說「現代電腦只相當於記憶空間有限的圖靈機,所以圖靈機解不了的,現代電腦也解不了」。這個結論是對的,但要小心:記憶體有限的電腦嚴格來說只是巨大的 FSM,理論上對它的停機問題是可判定的(狀態數有限,重複出現狀態就是迴圈),只是狀態多到實際不可行。所以不可判定性是針對「無限記憶體」的理想模型。
第 5 章:喬姆斯基的語法
5.1 生成規則的運作
文法就是改寫系統:從起始符號 S 出發,每次用某條規則「左式 ⇒ 右式」把字串中的左式換掉,直到全是終端符號。
教材的 grammar.gen:
1.  找到字串中第一個能匹配的非終端符號
2.  從它的右式選項中隨機選一個替換
3.  如果全是小寫(沒有大寫的非終端)就停止
程式前後補空白是為了匹配完整的符號,避免把 NP 裡的 N 誤當成另一個符號。這和第 1 章的推論引擎結構相同:找到可以展開的左邊,執行右邊的動作,只是「動作」不同。

5.3 為什麼文法對應機器
• 3 型 ↔ FSM:規則 A→aB 就是「在狀態 A 讀到 a 轉到狀態 B」,A→a 是「讀 a 後進入結束」。
• 2 型 ↔ 下推自動機(堆疊):aⁿbⁿ 的 S→aSb | ab,對應到「讀到 a 就 push,讀到 b 就 pop」,堆疊提供了「數 n」的能力。
• 1 型 ↔ 線性有界圖靈機:磁帶長度被限制在輸入長度的線性倍數內。
• 0 型 ↔ 圖靈機。
5.4 三個範例的細節
aⁿbᵐ(3 型):S→A,A→aA|B,B→bB|b。注意 B 至少產生一個 b,所以嚴格說這是 a*b⁺,m≥1。教材的 A→B 是單位產生式,屬於可以消除的形式。
aⁿbⁿ(2 型):S→aSb | ab。為什麼 3 型做不到?用泵引理:假設有 p 個狀態的 FSM,輸入 aᵖbᵖ,前 p 個字元內必有重複狀態,把重複那段 a 多繞幾圈,a 變多而 b 不變,但機器仍會接受,產生不屬於語言的字串,矛盾。
aⁿbⁿcⁿ(1 型):這條文法最巧妙,拆解如下:
1.  S→aBC | aSBC 先產生 aⁿ(BC)ⁿ,例如 aaBCBC
2.  這時 B、C 是交錯的,要想辦法讓所有 B 排到 C 前面。規則 CB→CZ, CZ→WZ, WZ→WC, WC→BC 是四步交換 CB 為 BC。不能直接寫 CB→BC,因為那不是 1 型允許的形式(左邊不是「單一符號加上下文」),所以繞四步,每一步只改一個符號
3.  全部排好得到 aⁿBⁿCⁿ,再由左而右轉成小寫:aB→ab, bB→bb, bC→bc, cC→cc
追蹤 n=2:aSBC → aaBCBC → aaBBCC(經過 CB 交換)→ aabBCC → aabbCC → aabbcC → aabbcc
這四條交換規則每一步都是 αAβ→αγβ 形式,而且字串長度不縮短,符合 1 型。aⁿbⁿcⁿ 不是 2 型,可以用 2 型的泵引理證明(泵引理的中間段最多影響兩種符號,第三種的數量不變)。

5.6 邱奇-圖靈論題
教材寫成「猜想」,通常稱為論題(thesis):任何「直覺上可有效計算」的函數,圖靈機都能計算。它不能被證明,因為「直覺上可計算」沒有形式定義。支持它的證據是:λ 演算、圖靈機、遞迴函數、Post 系統、0 型文法等完全不同的模型,能力都被證明等價。
全書總結:一條連貫的故事線
希爾伯特綱領 ── 想把所有數學機械化
    │
    ├─ 羅素悖論 → 集合論必須公理化(ZFC)
    ├─ 完備定理 → 純邏輯本身沒問題
    ├─ 不完備定理 → 足夠強的算術,必有不可證的真命題,
    │               而且無法證明自身一致(打掉完備性、一致性)
    ├─ 丘奇:λ 等價不可判定 ┐
    └─ 圖靈:停機問題不可判定 ┴→ 打掉確定性

共同手法:自我指涉 + 對角化
    羅素 {x|x∉x} → 哥德爾 「我不可證」 → 圖靈 U(U) → 丘奇

能力等價:λ 演算 = 圖靈機 = 0 型文法 = 一般程式語言
喬姆斯基階層:在圖靈機之下,還有 2、3、1 型各自對應較弱的機器
這份教材沒有涵蓋 P/NP 這類複雜度的內容,只到「可不可計算」。如果你的課程或考試也需要複雜度,那是接在這之後的下一個主題。
