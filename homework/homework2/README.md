# 遞迴關係式精確解與時間複雜度分析

本專案使用 Python 實作 4 種常見遞迴關係式的遞迴過程與數學精確解，透過實際程式執行結果對照，驗證數學推導與 Big-O 時間複雜度的正確性。

---

## 總覽與複雜度對照表

下表彙整 4 個遞迴關係式的精確數學公式與 Big-O 漸進複雜度：

| 遞迴關係式 | 初始條件 | 精確解 $T(n)$ | Big-O 複雜度 | 代表性演算法概念 |
| :--- | :--- | :--- | :--- | :--- |
| **1.** $T(n) = T(n-1) + 8$ | $T(1) = 1$ | $8n - 7$ | $\mathcal{O}(n)$ | 線性搜尋 / 固定疊加迴圈 |
| **2.** $T(n) = 2T(n-1) + 9$ | $T(1) = 1$ | $5 \cdot 2^n - 9$ | $\mathcal{O}(2^n)$ | 雙重遞迴（如河內塔、費式數列） |
| **3.** $T(n) = 2T(n/2) + 1$ | $T(1) = 1$ | $2n - 1$ | $\mathcal{O}(n)$ | 二元樹走訪 / 節點總數計算 |
| **4.** $T(n) = T(n/2) + 1$ | $T(1) = 1$ | $\log_2 n + 1$ | $\mathcal{O}(\log n)$ | 二元搜尋（Binary Search） |

> **註**：在包含 $n/2$ 的遞迴式中，預設 $n$ 為 2 的正整數次方（即 $n = 2^k$）。

---

## 數學推導簡介

### 1. $T(n) = T(n-1) + 8$
* **代入展開**：
  $$T(n) = T(n-1) + 8 = T(n-2) + 2 \cdot 8 = \dots = T(1) + 8(n - 1)$$
* **代入 $T(1)=1$**：$1 + 8n - 8 = \mathbf{8n - 7}$ $\rightarrow \mathcal{O}(n)$

### 2. $T(n) = 2T(n-1) + 9$
* **代入展開**：
  $$T(n) = 2T(n-1) + 9 = 2^2 T(n-2) + 2 \cdot 9 + 9 = \dots = 2^{n-1} T(1) + 9 \sum_{i=0}^{n-2} 2^i$$
* **等比級數求和**：$2^{n-1} \cdot 1 + 9 (2^{n-1} - 1) = 10 \cdot 2^{n-1} - 9 = \mathbf{5 \cdot 2^n - 9}$ $\rightarrow \mathcal{O}(2^n)$

### 3. $T(n) = 2T(n/2) + 1$
* **代入展開**（設 $n = 2^k \implies k = \log_2 n$）：
  $$T(n) = 2T(n/2) + 1 = 4T(n/4) + 2 + 1 = \dots = 2^k T(1) + (2^k - 1)$$
* **代入 $2^k = n$**：$n \cdot 1 + n - 1 = \mathbf{2n - 1}$ $\rightarrow \mathcal{O}(n)$

### 4. $T(n) = T(n/2) + 1$
* **代入展開**（設 $n = 2^k \implies k = \log_2 n$）：
  $$T(n) = T(n/2) + 1 = T(n/4) + 2 = \dots = T(1) + k$$
* **代入 $k = \log_2 n$**：$1 + \log_2 n = \mathbf{\log_2 n + 1}$ $\rightarrow \mathcal{O}(\log n)$
